# Rebalancing agent (placeholder)

Watches a PancakeSwap V3 LP position and resets the range when price drifts
out of it.

- Tools: `pancakeMyPosition`, `pancakeAddLiquidity`, `pancakeRemovePosition`
  (bsc-mcp — https://github.com/TermiX-official/bsc-mcp)
- Also the most direct route to the PancakeSwap partner challenge, alongside
  yield_optimization — no separate build needed there.

Run `bag init` in this folder to replace this file with a real agent.
